# EUC Library email design previews

Three sample HTML emails follow the existing cream, paper, maroon and gold design system: verification, password recovery and a library announcement. All names, identifiers, codes, links and notice content are synthetic. Links use the reserved `.example` domain. They are generated by the production `renderEmail()` function, including the shared branded layout. The samples themselves never send emails.

After installing backend dependencies, run `node artifacts/email-templates/build-previews.cjs` to regenerate the HTML. Open `index.html` or any individual template in a browser.

The layouts use presentation tables, inline styles, square edges and system font fallbacks (Georgia for serif headings; Arial for body text) to avoid depending on web fonts or externally loaded images. The narrow-screen media query reduces padding and type sizes. Real inbox clients may restyle colors or differ from the browser previews; validate in Gmail and Outlook before using the designs in live sending.
